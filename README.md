# Cursor Trail Picker

A Chrome extension that turns any image you choose into your mouse cursor trail.



## Features
- Pick any image from your computer
- Adjust size and trail length
- Optional spin and fade effects

## Install
1. Download the latest zip and unzip it.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and choose the unzipped folder.

## Use
Click the extension's toolbar icon, choose an image, and move your mouse.

## Limits
- Doesn't run on `chrome://` pages, the new tab page, or the Chrome Web Store.
- GIFs show as a still image.
